The **Integrations** tab connects BuildWorkPro to the other tools you use. Open it from **Settings -> Integrations**. Each integration is a card showing its status.

![Integrations settings tab with cards for Google Workspace, Claude & ChatGPT (MCP), Zapier, QuickBooks, and Xero](/docs-screenshots/settings/integrations-settings.png)

## Available integrations

- **Google Workspace** -- connect Gmail and Google Calendar to send email from your own address and sync project dates. See [connect Google](/docs/settings/connect-google/).
- **Claude and ChatGPT (MCP)** -- use BuildWorkPro from Claude or ChatGPT through the Model Context Protocol. Any other MCP client -- Claude Code, Grok Bot, OpenClaw, Hermes Agent -- uses the same connection. See the [MCP overview](/api/mcp/overview/) in the developer docs for the install guide per agent.
- **QuickBooks** -- sync invoices and payments with QuickBooks Online. Click **Connect** on the QuickBooks card and sign in with your Intuit account.

## Connected apps and developer tools

The **Developer & API** tab is the home for programmatic access -- **API Keys** and **Webhook Endpoints**. The apps you have authorized to act on your behalf, AI agents included, are listed under **Settings -> Authorized apps**, where each one can be revoked. API keys and webhooks are managed by Company Admins; see the [developer documentation](/api/) for how to use them.

<Aside type="note">
  **Role required:** Connecting Google and viewing the integrations list is open to all roles. Managing API keys and webhooks requires Company Admin.
</Aside>
